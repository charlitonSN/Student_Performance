Este conjunto de dados contém informações sobre 1000 alunos, incluindo hábitos de estudo (horas estudadas, frequência), fatores de estilo de vida (sono, atividades extracurriculares, trabalho de meio período), detalhes demográficos (gênero, educação dos pais) e resultados acadêmicos (nota da prova final e nota das letras). É ideal para análise exploratória de dados, regressão e tarefas de classificação para prever o desempenho dos alunos com base em fatores comportamentais e demográficos. Casos de uso: Previsão de notas de provas, classificação de notas, EDA sobre fatores de desempenho acadêmico, análise de importância das características.
